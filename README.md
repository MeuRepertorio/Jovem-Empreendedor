# J.E. — Jovem Empreendedor · Experiência pública experimental

Site demonstrativo do projeto J.E. em 2026, com identidade espacial, animações e interações para aprendizagem e validação de ideias.

## O que tem no site
- Apresentação / manifesto do J.E.
- Método interativo em quatro movimentos (observar, conectar, experimentar, evoluir).
- Universo com comunidade, Cadernos de Domínio e validação de ideias como conceitos **em desenvolvimento**.
- Laboratório de hipóteses: gera uma missão de pesquisa a partir de entradas do visitante **sem enviar dados à internet**.
- Amostra gratuita de Caderno com exercícios e verificação de compreensão.
- Layout responsivo, suporte a teclado, redução de movimento e links internos funcionais.

## Publicar no GitHub Pages
1. Crie um repositório público chamado `Jovem-Empreendedor` (ou outro nome).
2. Envie **o conteúdo** desta pasta para a raiz do repositório, incluindo `index.html`, `assets/` e `cadernos/`.
3. Entre em **Settings → Pages → Build and deployment**.
4. Escolha **Deploy from a branch**, branch `main`, pasta `/(root)`, e salve.
5. Abra o endereço indicado pelo GitHub em **Visit site**.

Se a conta for `MeuRepertorio` e o repositório se chamar `Jovem-Empreendedor`, o endereço previsto será `https://meurepertorio.github.io/Jovem-Empreendedor/` (sujeito à publicação e confirmação).

## Editar
- `index.html`: textos e seções da home.
- `assets/style.css`: visual e animações.
- `assets/app.js`: interações e laboratório.
- `cadernos/index.html`: amostra educativa.
- `cadernos/cadernos.css` e `cadernos/cadernos.js`: estilos e quiz da amostra.

## Limites e privacidade
Este é um **protótipo**: não possui login, pagamentos, comunidade ativa nem integração com banco de dados. A rede, os produtos e as parcerias citados são ideias em validação, não serviços comerciais comprovados. O formulário de ideias não salva ou envia dados a qualquer servidor. Não publique o painel interno anterior do projeto sem revisar suas informações.

## Atualizações
Ao alterar arquivos na branch publicada e confirmar o commit, o GitHub Pages deverá republicar a versão mantendo o endereço.
